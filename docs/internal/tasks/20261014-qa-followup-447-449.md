- Accounts decision: bound concurrently abandoned pending initializers to
  three per environment and handler mode (identity/control). A stale pending
  current attempt cannot be replaced when that would exceed this bound;
  callers get the existing secret-free 503/no-store/Retry-After response.
  Consequently each mode has at most four pending initializers including the
  current attempt, and both modes together have at most eight per environment.
  Obsolete fulfillment/rejection releases its slot without publishing its
  handler or dispatching old waiters. A fulfilled current attempt still
  recovers; a rejected current attempt can retry after the existing backoff
  because it has already released its current in-flight slot.
