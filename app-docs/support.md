# Takosumi サポート

## 公式窓口

Takosumi hosted service の公式サポート窓口は
[support@takosumi.com](mailto:support@takosumi.com) です。電話、チャット、
SNSのDMは公式受付として扱いません。

サービス全体の障害や計画メンテナンスは
[status.takosumi.com](https://status.takosumi.com/) で確認できます。

## 対応できる内容

- サインイン、Workspace、Dashboard、Runの不具合
- Takosumi hosted service のリソースと hosted service URL
- 使用量、請求、支払い方法、重複または誤った請求の調査
- データexport、アカウント削除、privacyに関する依頼
- セキュリティ上の問題

自分のProvider Connectionで接続した外部providerの契約、請求、quota、
provider側障害は、そのproviderのサポート対象です。顧客独自のResource定義や
アプリコードの開発代行は通常サポートに含みません。

## 問い合わせに含めるもの

- Takosumiアカウントのメールアドレス
- Workspace IDと、分かる場合はResource、Capsule、Run ID
- 発生日時とタイムゾーン
- 期待した動作と実際の動作
- 画面に表示されたrequest IDまたはerror code

API key、provider token、秘密鍵、カード番号、cookie、providerのstate exportは
送らないでください。必要な調査情報は、secretを除いて追加で案内します。

## 応答目標

通常の問い合わせは2営業日以内、productionのサインイン・請求・データexport
障害は1営業日以内に受付を確認します。営業日は日本の祝日を除く月曜日から
金曜日、JST 09:00–18:00です。詳細は[SLA](./sla.md)を参照してください。

受付確認は解決の約束ではありません。緊急障害は影響と安全性を優先して調査し、
広範な影響がある場合はstatus pageで案内します。
