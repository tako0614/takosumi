# Takosumi Cloud support

## Official channel

The official Takosumi Cloud support channel is
[support@takosumi.com](mailto:support@takosumi.com). Phone, chat, and social
media direct messages are not official support channels.

Check [status.takosumi.com](https://status.takosumi.com/) for broad incidents
and planned maintenance.

## What we support

- Sign-in, Workspace, Dashboard, and Run failures
- Takosumi Cloud resources and Cloud URLs
- Usage, billing, payment methods, and incorrect or duplicate charges
- Data export, account deletion, and privacy requests
- Security concerns

Contracts, billing, quotas, and outages for an external provider connected
through your own Provider Connection belong to that provider. General
development of customer-specific Resource definitions or application code is
not included in standard support.

## What to include

- The email address of the Takosumi account
- Workspace ID and, when available, Resource, Capsule, or Run ID
- Time of the event and timezone
- Expected and actual behavior
- A request ID or error code shown by the product

Do not send API keys, provider tokens, private keys, card numbers, cookies, or
raw provider state exports. We will ask for additional non-secret evidence
when needed.

## Response targets

We acknowledge general requests within two business days and production
sign-in, billing, or data-export incidents within one business day. Business
hours are Monday through Friday, 09:00–18:00 JST, excluding Japanese public
holidays. See the [SLA](./sla.md) for details.

Acknowledgement is not a fixed resolution-time promise. We prioritize impact
and safety, and publish broad incidents on the status page.
